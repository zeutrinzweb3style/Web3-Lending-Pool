# Web3 Lending Pool

A planning repository for a proposed USDT-only Web3 lending pool. Work is organized into gated phases; the current Phase 1 proposal is a non-financial application foundation only.

## Start here

- [Phase 1 implementation plan](plan.md)
- [Product proposal and requirements](docs/PRODUCT_SPEC.md)
- [Implementation phases and exit criteria](docs/PHASE_PLAN.md)
- [Decision log and open questions](docs/DECISIONS.md)
- [Security and privacy requirements](docs/SECURITY_AND_PRIVACY.md)
- [Current phase status](docs/PHASE_STATUS.md)
- [Developer and AI-agent working rules](AGENTS.md)

Every phase must end with a handoff report in `docs/handoffs/`. The next phase must not begin until the current phase's exit criteria are met and the product owner approves the handoff.

## Current status

Planning and Phase 1 implementation proposal only. No code scaffold, smart contracts, production services, public API, real-money pilot, legal review, security audit, or production identity verification has been completed. Open decisions are listed in `docs/DECISIONS.md` and must not be silently treated as approved requirements.
